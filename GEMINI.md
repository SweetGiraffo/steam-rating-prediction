# Project Instructions and Style Guidelines

## Core Directives
1. **Zero Emojis**: Never use emojis in any generated code, web interfaces, markdown documents, commit messages, or user responses.
2. **Minimalist Black Theme**: When designing web interfaces or visual assets, strictly adhere to a clean, simple, minimalist black theme (#000000 / #0a0a0a / #121212) with monochrome/grayscale accents, crisp borders (#222222), and clear readable typography. Avoid colorful gradients or neon aesthetics.
